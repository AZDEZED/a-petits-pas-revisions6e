# À petits pas · Révisions 6e

Cours, entraînements, défis et évaluations de mathématiques, histoire, sciences et musique/CHAM.

Version 0.2.0. A.Zeboudj.

L’application conserve le carnet dans le navigateur. Pour changer d’appareil ou de navigateur, exporter le carnet puis importer le même fichier. Garder cet export privé : il contient le code reliant les évaluations Google au carnet.

Les notes sont confirmées par Google Forms. Le détenteur du code peut consulter les résultats associés. Les points de pratique restent distincts des notes. Le questionnaire musical ne valide pas la justesse du chant.

Les sources théoriques et les liens musicaux sont accessibles depuis l’application. Une connexion Internet est nécessaire pour les évaluations et les ressources externes.

Ce dépôt contient uniquement les fichiers publics du site. Il ne contient ni copie d’élève, ni export de carnet, ni documents de travail privés.

Publication GitHub Pages depuis la branche main, dossier racine. Application HTML/CSS/JavaScript sans compilation.
